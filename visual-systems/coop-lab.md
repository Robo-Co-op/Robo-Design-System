# Co-op Lab Visual System

**Startup Together — Cooperative Entrepreneurship Lab**

The visual language combines credible venture building with constructive rebellion.

- Foundation: blush/white or burgundy-dark
- Signal: coral / primary red
- Counterpoint: Creative Purple + Cyan
- Motif: offset blocks, overlapping ownership tiles
- Core: partner-ready
- Hack: editorial, manifesto-like, slightly brutalist

Avoid generic startup gradients and chaotic zine styling.
