# Robo Co-op Visual System

**Support Together — Human⇄Machine Cooperative OS**

Robo Co-op should feel like a trustworthy operating system for cooperation.

- Foundation: Circuit White / Robo Black
- Connection signal: Sync Cyan
- Human agency / decision signal: Coop Amber
- Motif: paired rails, synchronization points, handoff
- Core: calm, credible, governance-ready
- Dark OS: higher-contrast keynote mode

Avoid generic AI neon, robot clip-art, and decorative circuit-board wallpaper.
